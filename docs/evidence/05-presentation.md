## 우리 근거

### 가지고 있는 것

- 프로토타입 12개 화면이 돈다 → 스크린샷·녹화 소재가 이미 있다
- 개요 화면에 서비스 정의·판정 체계·데이터 출처·범위 밖이 정리돼 있다
- 수치가 전부 출처와 붙어 있다

### 없는 것

**발표자료 자체.** 한 장도 없다.
**시연 영상.** 촬영 안 했다.
