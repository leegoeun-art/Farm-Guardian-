## 우리 근거

### 관점 1 — 빈칸을 통과로 넘기지 않는다

보통은 데이터가 비면 조용히 넘긴다. 우리는 **비었다는 사실 자체를 화면에 띄운다.**

```
확인 필요 (UNKNOWN)   값이 없어서 확인을 못 했다
심을 때   (NA)        항목 자체가 해당되지 않는다
```

둘을 따로 둔 게 핵심이다. **「모름」과 「해당 없음」은 다르다.**
심을 때 땅에 넣는 약에는 「수확 며칠 전」이라는 개념 자체가 없다. 이걸 「모름」으로 묶으면
농가는 「자료가 부실하구나」로 읽고, 「통과」로 묶으면 법을 어긴다.

판정 상태가 보통 3개(가능·주의·불가)인데 우리는 **5개**다.
→ `docs/internal/팜가디언_제품쟁점.md` 11번

### 관점 2 — 법 문제와 효과 문제를 색으로 갈라놨다

| | 걸리면 | 색 |
| --- | --- | --- |
| ①등록 ②시기 ③횟수 | 출하가 막힌다 | 불가 (빨강) |
| ④계통 | 약이 덜 듣는다 | 주의 (노랑) |

같은 「문제」지만 **결과의 무게가 다르다.** 농가가 급할 때 ④만 걸렸으면 뿌려도 된다.
이걸 한 덩어리로 묶으면 농가는 전부 무시하게 된다.

### 관점 3 — 저항성을 「지역 단위」로 봤다

개별 농가는 자기 밭만 본다. 저항성은 지역 단위로 퍼진다.
옆 밭이 전부 같은 계통을 쓰면 혼자 바꿔도 이미 저항성을 가진 벌레가 넘어온다.

그래서 면 단위로 계통 사용 비중을 모아 보는 화면을 설계했다 (FR-503, P2).
개인 화면에서는 보이지 않는 층이다.

### 관점 4 — 판정만 내놓지 않고 근거 원문을 같이 보여준다

「불가」라고만 하면 농가는 안 믿는다. 번호를 누르면 **PSIS 원문 그대로**가 나온다.
「수확7일전」「3회」「정식기」 같은 원문이다. 우리가 요약한 말이 아니다.
