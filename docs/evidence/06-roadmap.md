## 우리 근거

### 현장 적용 가능성

| 근거 | 내용 |
| --- | --- |
| 대상 데이터가 전국 단위 | PSIS·NCPMS는 전국 자료다. 작물만 늘리면 지역이 늘어난다 |
| 외부 API 의존 없음 | 판정 중에 외부를 부르지 않는다. 망이 약한 밭에서도 돈다 |
| 고령 사용자 고려 | 글자 크기·대비 기준 통과. 용어 풀이 화면 제공 |

현재 작물 3종(감자·배추·토마토). 같은 구조로 작물을 늘리는 데 추가 설계가 필요 없다.
등록약 데이터가 작물별로 같은 형식이기 때문이다.

### 후속 연구

| 방향 | 근거 |
| --- | --- |
| 면 단위 계통 쏠림 지표 | FR-503 (P2). 개인 화면에 없는 층 |
| 계통 쏠림과 실제 저항성의 상관 | 지금은 「쏠렸다」만 말한다. 생물검정과 이어붙이면 연구가 된다 |
| 지역별 약효 차이 | 42.3%(평창) vs 100%(성주·거창) — 왜 다른가 |
