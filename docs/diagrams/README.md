# 팜가디언 Mermaid 도식

`.mmd` 파일이 정본이다. **이 README에 코드를 복사해 두지 않는다** — 두 벌이 되면 반드시 어긋난다.

## 보는 법

1. `.mmd` 파일 전체를 복사한다 (코드만 들어 있다)
2. [Mermaid Live Editor](https://mermaid.live/edit)에 붙여넣는다
3. 필요하면 SVG로 저장한다

편집기 permalink는 만들지 않는다. 도식을 고쳐도 링크가 갱신되지 않아 낡은 그림이 남는다.
