## P-01. 이승준(A) — 배추 재배를 처음 시작해 병해충, 약제 정보와 기록에 익숙하지 않은 사용자

### 인물

배추를 한 구역에서 재배하기 시작했다. 병해충 이름·약제 계열·사용기준 용어가 낯설고, 팜가디언을 처음 사용한다. 서비스에 저장된 살포 이력은 0건이다.

### 처한 상황

밭에서 배추 잎의 이상 증상을 발견했다. 약제를 사용하기 전에 무엇을 확인해야 하는지 알아보려고 휴대폰을 꺼낸다.

### 목표

도감의 사진·이름을 보고 병해충 후보를 살펴보고 싶다. 선택한 약제에서 확인 가능한 사용조건과 정보가 부족한 조건을 구분하고 싶다.

### 겪고 있는 어려움

증상만 보고 병해충 이름을 확신하기 어렵다. 살포 이력이 없을 때 표시되는 ‘확인 필요’가 어떤 정보의 부족을 뜻하는지도 이해하기 어렵다.

### 사용 순서

1. 내 밭에서 사용할 구역을 선택하고 작물이 배추인지 확인한다. 처음 이용한다면 밭과 구역을 먼저 등록한다.
2. 증상 부위를 선택하고 도감의 병해충 사진·이름을 살펴본다.
3. 병해충을 확신하지 못하면 선택하지 않고 다음 단계로 넘어간다.
4. 확인하려는 약제를 목록에서 선택한다.
5. 네 개의 체크(작물·병해충에 대한 약제 등록 여부, 수확 가능 날짜, 남은 사용횟수, 같은 계통의 약제 반복 사용)의 결과를 읽는다.
6. ‘확인 필요’로 표시된 항목을 열어 어떤 정보가 부족한지 읽고, 근거 원문과 데이터 기준일을 확인한다.



## P-02. 박민수(B) — 익숙한 감자 약제는 알지만 살포 날짜·횟수는 기억에 의존하고 기록은 드문 사용자

### 인물

감자를 재배하며 자주 사용하는 약제가 있다. 작물과 익숙한 제품명은 알지만 살포 날짜·횟수는 주로 기억에 의존한다. 팜가디언에는 살포 이력의 일부만 기록되어 있다.

### 처한 상황

다음 살포를 준비하며 평소 쓰던 약제의 포장을 확인한다. 그 약제의 현재 등록정보와 사용기준을 살펴보려고 휴대폰으로 팜가디언을 연다.

### 목표

익숙한 약제의 등록 여부·안전사용기준·작용기작 계열을 확인하고 싶다. 이후에는 살포한 구역·약제·날짜를 빠뜨리지 않고 기록하고 싶다.

### 겪고 있는 어려움

과거 살포 날짜와 횟수를 정확히 떠올리기 어렵다. 제품명이 달라졌을 때 작용기작 계열도 달라졌는지 판단하기 어렵고, 누락된 기록 때문에 표시된 횟수가 실제 전체 사용을 반영하는지 확신하지 못한다.

### 사용 순서

1. 사용할 감자 구역을 선택하고 도감에서 알고 있는 병해충을 선택한다.
2. 등록 약제 목록에서 평소 사용하던 제품을 찾고 제품명·성분·국내 계열 코드를 확인한다.
3. 네 개의 체크(작물·병해충에 대한 약제 등록 여부, 수확 가능 날짜, 남은 사용횟수, 같은 계통의 약제 반복 사용)의 결과와 안전사용기준 원문·데이터 기준일을 확인한다.
4. 살포 기록 목록을 열어 기억하고 있는 과거 살포와 비교하고, 빠진 기록이 있는지 살펴본다.
5. 살포 후 구역·약제·날짜를 확인하고 기록 버튼을 누른다.
6. 해당 구역의 기록 목록을 열어 방금 기록한 내용이 맞는지 확인한다.

## P-03. 김서현(C) — 살포 기록은 꾸준히 남기지만 약제의 안전사용기준을 해석하기 어려운 사용자

### 인물

배추를 재배하며 살포 후 구역·약제·날짜를 팜가디언에 꾸준히 기록한다. 약제의 안전사용기준 문장과 작용기작 계열 코드의 의미는 이해하기 어렵게 느낀다.

### 처한 상황

다음 살포를 준비하며 휴대폰에서 해당 구역의 이력을 확인한다. 이번에 사용할 약제의 수확 관련 조건과 남은 사용횟수를 살펴보려 한다.

### 목표

선택한 약제의 사용조건을 이해하고 수확 가능 날짜·남은 횟수·같은 계통의 사용 카운트를 확인하고 싶다. 사용한 약제는 올바른 구역에 기록하고, 잘못 기록한 내용은 취소하고 싶다.

### 겪고 있는 어려움

살포 기록이 있어도 안전사용기준 문장을 자신의 사용 상황에 어떻게 적용하는지 이해하기 어렵다. 계열 코드와 ‘주의·확인 필요’의 사유를 읽는 데 설명이 필요하다.

### 사용 순서

1. 사용할 배추 구역을 선택하고 정식일과 살포 기록 목록을 확인한다.
2. 도감에서 병해충을 선택하고 등록 약제 목록에서 사용할 약제를 선택한다.
3. 네 개의 체크(작물·병해충에 대한 약제 등록 여부, 수확 가능 날짜, 남은 사용횟수, 같은 계통의 약제 반복 사용)의 결과를 읽는다.
4. 이해하기 어려운 약제 사용조건이나 ‘주의·확인 필요’ 항목을 열어 사유·근거 원문·데이터 기준일을 확인한다.
5. 살포 후 구역·약제·날짜를 확인하고 기록 버튼을 누른다.
6. 잘못 기록한 내용이 있으면 해당 기록을 선택해 취소하고, 기록 목록과 남은 사용횟수·같은 계통의 사용횟수를 다시 확인한다.

## P-04. 정지훈(D) — 여러 구역의 살포 이력을 관리하며 구역별 약제 사용조건과 계통 반복을 확인하는 사용자

### 인물

배추·토마토를 여러 구역에서 재배한다. 작물·약제에 익숙하고 팜가디언에 구역별로 기록을 남긴다. 구역마다 사용한 약제와 살포 날짜가 다르다.

### 처한 상황

다른 구역에서 사용한 약제를 이번 구역에도 사용할 수 있는지 확인하려 한다. 밭에서 휴대폰으로 구역을 바꾸어 가며 이력과 약제의 사용조건을 살펴본다.

### 목표

선택한 구역의 이력에 맞는 사용횟수·계통 반복 결과를 확인하고 다른 계통의 대안을 비교하고 싶다. 살포 기록을 정확한 구역에 남기고 싶다.

### 겪고 있는 어려움

구역을 바꿀 때 어떤 구역의 작물·이력·판정인지 혼동할 수 있다. 여러 구역에서 사용한 제품명을 기억하는 것만으로 현재 구역의 계통 반복 여부를 확인하기 어렵다.

### 사용 순서

1. 내 밭에서 사용할 구역을 선택하고 구역명과 작물을 확인한다.
2. 해당 구역의 살포 기록 목록을 살펴본 뒤 병해충과 약제를 선택한다.
3. 네 개의 체크(작물·병해충에 대한 약제 등록 여부, 수확 가능 날짜, 남은 사용횟수, 같은 계통의 약제 반복 사용)의 결과와 사유·근거를 확인한다.
4. ‘불가·주의’가 표시되면 다른 계통의 대안 약제를 열어 사용조건과 근거를 비교한다. 대안이 없으면 농업기술센터 문의 안내를 확인한다.
5. 다른 구역을 선택해 그 구역의 작물·살포 기록·약제 사용조건을 살펴본다.
6. 살포 후 기록할 구역을 다시 선택하고 약제·날짜를 확인해 기록한 뒤 해당 구역의 기록 목록을 확인한다.
